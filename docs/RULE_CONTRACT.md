# Rule contract / Hợp đồng luật

This document is the rule source for the application. The original 56-card deck and core turn rules follow the [Original Edition instructions](https://www.explodingkittens.com/pages/rules-kittens) and [official field guide](https://www.explodingkittens.com/pages/comprehensive-field-guide), subject to the explicit online timing and privacy rules below. The eight 64-card effects and Resurrection are **application expansion rules / luật mở rộng của ứng dụng**, not claimed to be official Original Edition rules.

The request's joined ranges are read as 2–5 players, 2–3 players, 16–32 px, 45–75 seconds, 180–550 ms, and 1–2 Resurrection cards. A 56-card deck cannot deal eight cards to 25 players. The application supports 2–5 active players per game.

## Base game

Deck: 4 Exploding Kitten, 6 Defuse, 4 each Attack/Favor/Shuffle/Skip, 5 each Nope/See the Future (3x), and 4 each of five Cat Card titles. Every physical card has its own instance ID. For N players: each gets 1 Defuse and 7 shuffled non-Defuse/non-Kitten cards; add min(2, 6-N) extra Defuses and N-1 Kittens to the shuffled draw pile. All unused cards are removed from the match, counted in a server-only zone.

Turn debt counts complete turns still owed. Drawing, Defusing an explosion, or using Skip completes exactly one turn. An ordinary Attack ends the actor's turn and gives the next living player **two** turns. If the actor is still resolving inherited Attack debt, Attack ends all their remaining debt and gives the next living player that remaining debt **plus two**. After finishing one of two inherited turns, an Attack therefore gives the next player three turns. See the Future only exposes the next min(3, deck size) ordered cards to its owner. A matching pair steals one random card. A matching triple asks for a card type; the target gives one if available. Combo cards have no printed effects when used in a combo.

An ordinary played action first enters a timed Nope window; its effect starts only after the window closes. Every Nope toggles whether the original action is cancelled. The Nope cards themselves go to discard. Exploding Kitten and Defuse never enter a Nope window. The acting player supplies a required target/type with the initial action, before the Nope window. Public logs use translation keys and public parameters only. Private knowledge from See the Future, Creepy Peeky, steals, and the chosen middle insertion index never enters public events.

After a Defuse, the player privately chooses a slot 0..N inclusive in the remaining deck, with 0 at the top and N at the bottom. Public resolution is exactly `TOP`, `BOTTOM`, or `MIDDLE_HIDDEN`; every middle slot produces the same public payload, log, reconnect snapshot, and animation parameters. The exact slot remains server-only. Defusing completes one owed turn. A player eliminated without Defuse keeps their unrevealed hand in a server-only eliminated zone; their Kitten is placed in their eliminated zone. The last living player wins.

## Online decisions

Timers run on the server. Normal turns default to 30 seconds; Nope windows to 7 seconds; required card/target/position choices to 20 seconds. A normal-turn timeout draws one card. A Nope timeout closes the window. A Favor or Battle Hamster choice timeout chooses a valid card by server RNG. A Defuse timeout chooses a valid insertion slot by server RNG, with the same public privacy classification. A Hip Cat timeout chooses rock/paper/scissors by server RNG. Disconnected players keep their seats; these same deterministic fallback *rules* apply when their timer expires. Server RNG outcomes remain unpredictable.

Unless an effect explicitly says otherwise, playing a card requires the actor to be living, in their own active turn, and to own its exact instance ID. Targets must be living opponents. Played cards enter discard immediately; their effect remains pending until the Nope window closes. A cancelled action remains discarded. If a target is eliminated during a pending choice, its effect resolves as no effect. If a match ends, all pending choices close without effect. No card effect waits for client animation.

Room timing is an application rule: changing deck/resurrection options clears all ready flags; starting requires everyone to be connected and ready. A host disconnected for 120 seconds hands control to the first connected seat. Game seats remain available for reconnect. Expired obligations resolve before actions received after their deadline are validated.

## 64-card expansion: eight application rules

All eight extra types are single physical cards. A played extension card can be Noped in the normal pre-effect window, including if it will have no useful effect. Required choices are server validated; a disconnected player may rejoin and answer before the deadline.

| Amateur Archaeology | Own turn; choose an eligible card instance from the public discard after the Nope window. | Any discard except Exploding Kitten or a pending action card may be chosen. Server inserts it at a random slot in the draw pile. Chosen type is public; insertion slot and new order are server-only. | If no eligible discard, action resolves without moving a card. If the chosen card left discard, choose again or timeout fallback. | Server chooses a random eligible discard on timeout; no card means no effect. |

| Creepy Peeky | Own turn; choose a living opponent. | Actor alone receives the target's current hand with instance IDs. Others only see action key/target; no hand data in log or spectator view. | Empty hand returns an empty private view. | No choice after target; disconnected actor receives current snapshot/private result only if still entitled; timed action otherwise resolves. |
| Hip Bat | Own turn; attach to living opponent. | For that player's next three **starts of a turn**, before they can act, they discard one hand card; attachment count is public, chosen card remains private until discard. Multiple bats each demand one discard independently. | At a turn start with no cards, consume that bat trigger with no discard. Elimination removes attachments. | Victim has 20 seconds per required discard; server RNG picks on timeout. |

Otherwise winner takes up to two. Eligible cards are the latest ordinary discard cards, excluding Exploding Kitten and Hip Cat itself. Taken types are public because they were public discards; hand contents otherwise stay private. | For a tie with one eligible card, actor gets it first; with none, neither gets one. Winner receives as many as available, up to two. | Each missing choice is selected by server RNG at 20-second deadline. |
| Plus Plus | Own turn; play **together** with an owned numeric action: Attack, See the Future, or Hip Bat. The paired action's ordinary target requirements apply. | Its printed numeric effect increases by exactly one: Attack adds three turns, See views four cards, Hip Bat lasts four starts. Both cards are discarded; both can be cancelled together by one Nope window. Public log reveals the paired type, not private viewed cards. | If fewer cards/targets exist, apply min(available, increased number). Cannot pair with Skip, Favor, any nonnumeric card, or a combo. | The normal action and target timers apply. |
| Robin Hood | Own turn; no target. | Server collects all living players' full hands, shuffles once, deals equally across living players; remainder cards go one each in server-random seat order. Public sees only new hand counts. Individual hands remain private. | Empty total hands remain empty; no extra cards are created. | Effect resolves server-side at Nope close even if actor disconnects. |
| The Twins | Own turn; no target. | Each **other living** player gives the actor every full pair of the same title in their hand: 2 cards yields 2, 3 yields 2, 4 yields 4. Each donor's remainder stays theirs. Public sees donor and number, never hidden card types or instance IDs; actor sees received cards. | No pairs means no transfer. | Effect resolves server-side at Nope close even if any donor disconnects. |

Robin Hood and The Twins never move eliminated players' preserved hands. Normal game end takes precedence over any unresolved effect. Extension cards may appear in legal same-title combos only if there are enough physical copies; this 64-card set has one of each, so they cannot form their own pair or triple.

## Resurrection / Hồi Sinh: optional application rule

Off by default; when enabled, add **two** Resurrection cards after base/64 setup and shuffle them into the draw pile. This changes the total to 58 or 66 cards. Only a living player may play one on their own turn and name an eliminated player. The action can be Noped before it starts. The revived player receives their exactly preserved secret hand. Their eliminated Kitten is inserted by server RNG into the draw pile; its position is never published. They rejoin turn order from the following circuit of the table, not in the middle of the current active turn. The game cannot be resurrected after a winner is declared. If no player is eliminated, the card cannot be played. On revival, the invariant `active Kitten count = living player count - 1` is restored. A cancelled Resurrection remains discarded and changes neither player nor Kitten state.

## State and privacy

State phases: `LOBBY → TURN → NOPE_WINDOW → (TARGET_CHOICE | HIP_CAT_CHOICE | BAT_DISCARD | TURN) → EXPLOSION → DEFUSE_INSERT → TURN/RESULT`; `RESULT → LOBBY` for rematch. Not every action visits every phase. The server keeps the full deck, all hands, pending secrets, and per-player eliminated zones. Public snapshots hold counts, phases, deadlines, and only public card identities. A private snapshot adds the viewer's own hand and obligations. Spectators get the public snapshot only. Every intent carries `gameId`, `turnId`, `actionId`, `expectedRevision`; room processing is serialized, retries are idempotent, stale revisions fail with a translatable code.
